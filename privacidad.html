Política de Privacidad

DaniMarvis Store — Panel de gestión

Esta política explica qué datos maneja el panel de gestión DaniMarvisStore, dónde se guardan y quién puede verlos.

Qué datos guarda

  • Productos, proveedores, ventas, órdenes, garantías y formas de pago.
  • Fotografías de productos y material gráfico generado para redes sociales.
  • Publicaciones planeadas y el historial de grupos de Facebook donde se publican.
  • Copias de seguridad de la base de datos y de las imágenes.

Dónde se guardan

Los datos se guardan en el equipo del responsable del proyecto. Las copias de seguridad se generan de forma automática y se almacenan en una carpeta de Google Drive de la cuenta del responsable, usando una cuenta de servicio creada exclusivamente para este fin.

Las copias contienen solo datos que ya estaban en el equipo. Se transfieren cifradas y no se comparten con terceros ni se usan con fines publicitarios.

Acceso a los datos

El acceso está limitado al responsable del proyecto y, cuando se subcontracta soporte técnico, al personal estrictamente necesario para la tarea. No se venden datos ni se comparten con terceros.

Retención y eliminación

Los datos se conservan mientras la operación esté vigente. Las copias de seguridad se van reemplazando de forma automática y se eliminan las más antiguas.

Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos en cualquier momento. También puedes revocar el acceso de la cuenta de servicio a Google Drive desde la configuración de tu cuenta de Google; esto no afecta los datos guardados en el equipo.
